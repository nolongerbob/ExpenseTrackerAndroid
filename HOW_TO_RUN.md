# 🚀 Как запустить Android приложение

## Проблема: Кнопка Run неактивна

Это означает, что Android Studio не видит конфигурацию запуска или нет выбранного устройства.

## Решение:

### Вариант 1: Создать виртуальное устройство (AVD)

1. **Откройте Device Manager:**
   - В Android Studio: **Tools → Device Manager**
   - Или нажмите на иконку телефона в верхней панели

2. **Создайте устройство:**
   - Нажмите **"Create Device"**
   - Выберите любое устройство (например, **Pixel 5**)
   - Нажмите **Next**

3. **Выберите систему:**
   - Выберите любую версию Android (например, **Android 13 (API 33)**)
   - Если системы нет, нажмите **Download** и дождитесь загрузки
   - Нажмите **Next** → **Finish**

4. **Запустите приложение:**
   - В верхней панели выберите созданное устройство из выпадающего списка
   - Нажмите зеленую кнопку **Run** (▶️) или **Shift + F10**

### Вариант 2: Подключить реальное Android устройство

1. **Включите режим разработчика:**
   - На телефоне: **Настройки → О телефоне**
   - Нажмите 7 раз на **"Номер сборки"**
   - Появится сообщение "Вы стали разработчиком"

2. **Включите отладку по USB:**
   - **Настройки → Система → Параметры разработчика**
   - Включите **"Отладка по USB"**

3. **Подключите телефон:**
   - Подключите телефон к компьютеру через USB
   - На телефоне разрешите отладку по USB (если появится запрос)

4. **Запустите приложение:**
   - В Android Studio в верхней панели выберите ваше устройство
   - Нажмите **Run** (▶️)

### Вариант 3: Создать конфигурацию запуска вручную

1. **Run → Edit Configurations...**
2. Нажмите **+** → **Android App**
3. Название: **app**
4. Module: выберите **app**
5. Нажмите **OK**
6. Теперь кнопка Run должна стать активной

## Если ничего не помогает:

1. **Invalidate Caches:**
   - **File → Invalidate Caches / Restart**
   - Выберите **"Invalidate and Restart"**

2. **Проверьте синхронизацию:**
   - **File → Sync Project with Gradle Files**

3. **Проверьте, что проект собран:**
   - **Build → Make Project** (Ctrl+F9 / Cmd+F9)

## После успешного запуска:

Приложение должно:
1. Показать экран онбординга (если первый запуск)
2. Или экран входа (если онбординг уже пройден)
3. После входа - главный экран (Dashboard)
